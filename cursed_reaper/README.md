# Cursed Reaper Scythe (เคียวยมทูตต้องสาป)

ธีม: คำสาป • เงา • จันทร์เสี้ยว • พลังสีแดงดำ — เคียวโมเดล poly mesh + สกิล 6 ท่า + คอมโบโจมตีปกติ 3 จังหวะ
พร้อมอนิเมชั่นท่าถือ / ท่าโจมตี / ท่าร่ายทุกสกิล

## ไฟล์สำหรับ Blockbench (`model/`)
| ไฟล์ | |
|---|---|
| `cursed_reaper_scythe.bbmodel` | โมเดลเคียว **poly mesh** (แยก 4 ชิ้น: blade / head / shaft / pommel, ~5,300 poly) ฝังเท็กซ์เจอร์ในไฟล์แล้ว |
| `cursed_reaper_animations.bbmodel` | ตัวผู้เล่นจำลอง + เคียวในมือ + **อนิเมชั่นทั้งหมด 11 ท่า** เปิดแท็บ Animate แล้วกดเล่นดูได้เลย |
| `cursed_reaper_scythe.png` | เท็กซ์เจอร์ของเคียว |

เปิดด้วย File → Open Model ได้ทันที (ไฟล์เป็นรูปแบบ **Generic Model** เพราะ Blockbench รองรับ mesh เฉพาะรูปแบบนี้
รูปแบบ Bedrock ของ Blockbench ยังเปิด/ส่งออก `poly_mesh` ไม่ได้) — ตัวที่ใช้ในเกมจริงเป็น `poly_mesh` ที่สคริปต์สร้างให้จาก mesh เดียวกัน

## ติดตั้ง
1. เปิด `dist/Cursed_Reaper_Scythe.mcaddon`
2. เปิด Behavior Pack + Resource Pack ในโลก (Minecraft Bedrock 1.21.40 ขึ้นไป)
3. `/give @s idex:cursed_reaper_scythe` หรือคราฟต์: เนเธอไรต์ 3 + กุหลาบวิเธอร์ + เบลซร็อด 2 + บล็อกเรดสโตน

| ปุ่ม | ผล |

| ตี (คลิกซ้าย โดนมอบ/บล็อก) | คอมโบ 3 จังหวะ: เหวี่ยงกว้าง → ตวัดขึ้น → หมุนตัวสับลง |

## ทำงานอย่างไร
- **ท่าทาง**: อนิเมชั่นผู้เล่นทั้งหมดอยู่ใน `Cursed_Reaper_RP/animations/reaper_player.animation.json` เล่นผ่าน `/playanimation` จากสคริปต์
  (ไม่ทับไฟล์ `player.entity.json` จึงใช้ร่วมกับแอดออนอื่นที่แก้ player ได้) ท่าถือสองมือเล่นวนตลอดที่ถือเคียว
- ท่าทั้งหมดสร้างจาก rig: กำหนดตำแหน่งมือขวา + ทิศด้าม/ใบมีด แล้ว IK จับมือซ้ายให้อยู่บนด้ามจริง และตรวจว่าใบมีดไม่จมดิน
- **Red Trail** คำนวณจากท่าเดียวกัน (forward kinematics ของปลายใบมีดทุก tick) → `scripts/reaper_data.js` จึงตรงกับวงสวิงจริง
- เคียวในมือ: attachable `poly_mesh` + ลายแดงเรืองแสง (`entity_emissive_alpha`) + ประกายไฟวิ่งตามขอบใบมีด
- เอฟเฟกต์: particle 23 แบบ (วงเวท 3 ชั้น, โซ่, รูน, จันทร์, สุริยุปราคา, รอยแยก, คลื่น void ฯลฯ) และ entity 3 ตัว
  (คลื่นจันทร์เสี้ยว, เคียวเงา, afterimage) ซึ่งเป็นโมเดลคิวบ์ เพราะ `poly_mesh` บน entity ไม่แสดงผล

## ข้อควรรู้
- ยังไม่ได้ทดสอบในเกมจริง: ตรวจด้วย validator, render ท่าจาก rig, และรันสคริปต์กับ mock ของ `@minecraft/server` ทุกสกิลไม่มี error
  ค่าที่อาจต้องจูนหลังลองในเกม: มุมเคียวในมือ, ขนาด, ความแรงการดึงของโซ่
- มุมมองบุคคลที่ 1 ซ่อนเคียวและไม่ใช้ท่าถือ (เหมือนดาบคาทานะเดิม) เพื่อไม่ให้เคียวยาวบังจอ
- เสียงใช้เสียง vanilla
- ท่าโจมตีเริ่มเมื่อ "ตีโดน" มอบหรือบล็อก (Script API รุ่น stable ยังจับการเหวี่ยงลมไม่ได้)
